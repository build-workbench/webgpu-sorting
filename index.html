⚡ 双调排序 (Bitonic Sort)

复杂度: O(n log²n) 特性: 数据无关 (Data-Oblivious) 适用: 中小规模与规整块

双调排序基于经典的排序网络（Sorting Network），每个 stage 包含多次跨步比较。每个线程在 GPU 核心中执行固定的比较交换逻辑，无分支发散，极其适合 GPU SIMD 架构与 Workgroup 局部共享内存。

// WGSL 局部双调排序核心比较逻辑 let partner = local_idx ^ pair_distance; if (partner > local_idx) { let ascending = ((local_idx / block_size) % 2u) == 0u; if ((data[local_idx] > data[partner]) == ascending) { // 比较并交换 (无需锁与分支预测) swap(local_idx, partner); } } workgroupBarrier(); // 同步共享显存

🚀 基数排序 (Radix Sort)

复杂度: O(n × k) 特性: 4-Bit 8轮流水线 适用: 百万级大规模 32位整数

针对 32 位无符号整数，划分为 8 轮（每轮 4 bits，对应 16 个直方图桶）。每一轮通过 3 个 Compute Pass 流水化执行：

  1. 直方图计算：256 线程工作组统计各自 16 桶计数。
  2. GPU 并行前缀和：利用 Blelloch Scan 快速算出全局偏移量。
  3. 稳定散射重排 (Scatter)：将元素无冲突写入乒乓缓冲区。
// Radix 3阶段流水线 passEncoder.setPipeline(histogramPipeline); passEncoder.dispatchWorkgroups(numWorkgroups); // Blelloch 前缀和流水线 scanModule.computePrefixSumGPU(histogramBuffer, ...); // 稳定分散 passEncoder.setPipeline(scatterPipeline); passEncoder.dispatchWorkgroups(numWorkgroups);
